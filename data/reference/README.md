# 业务参考编码数据

本目录保留未经业务转换的外部参考数据。系统导入时应建立独立的版本记录、来源 URL、文件校验值和导入时间；不得直接修改原始文件。

| 文件 | 用途 | 来源与版本 | 说明 |
| --- | --- | --- | --- |
| `icd-10-national-clinical-v2.xlsx` | 疾病诊断名称与 ICD-10 国家临床版编码基线 | 福建省卫生健康委员会发布的《疾病分类与代码国家临床版 2.0》（2019） | 工作表 `2.0（导入系统库）`，37,292 行、3 列；字段为主要编码、附加编码、疾病名称。SHA-256：`435ccd9376fe71920d26d399d831f499a473ae5632654c2e1d6ae1e2d97e9951`。 |
| `icd-10-national-clinical-v2.json` | 种子程序使用的疾病字典转换文件 | 由同目录 Excel 无损提取 | 34,708 条可导入疾病记录。 |
| `china-admin-divisions-gbt2260.json` | 省、市、县三级行政区划六码字典 | `mumuy/data_location`（MIT），依据 GB/T 2260 整理 | JSON 键为六码、值为名称；当前含 3,433 条。SHA-256：`848d00f6e09ea3d292c666648f763920ab8c94b8c83874971c680bf168cf307a`。 |

## 使用边界

- 疾病条目应以“主要编码 + 可选附加编码”作为唯一诊断编码，不应只按疾病名称匹配。
- 地区只使用六码 GB/T 2260 编码：前两位为省级、中间两位为市级、末两位为县级。
- 医疗机构编码仍应从国家医保局定点医疗机构代码库的授权导出或接口同步；该库需要登录，未在此目录放入替代数据。
- 每次更新需保留旧版并记录生效日期，避免历史理赔记录随区划或诊断字典变更而失去可追溯性。
