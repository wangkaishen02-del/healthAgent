# 编号与代码口径

为了避免业务口径混乱，当前系统统一按下面的规则使用“编号 / 代码 / 号”类字段：

## 1. 保单

- `policyNo`
  保单号，业务可见，唯一

## 2. 被保人

- `insuredNo`
  被保人编号，全系统唯一，业务可见

说明：

- 不再使用 `memberNo`
- 被保人清单、后续理赔关联、跨保单查询都统一使用 `insuredNo`

## 3. 险种

- `productCode`
  险种代码，给业务人员看，同类险种跨保单可重复
- `productNo`
  险种编号，系统唯一，标识某张保单下的这条险种实例

## 4. 责任

- `benefitCode`
  责任代码，给业务人员看，同类责任跨保单可重复
- `benefitNo`
  责任编号，系统唯一，标识某张保单下的这条责任实例

## 5. 使用原则

- 给业务查阅、比对、沟通时，优先展示“代码”
- 做系统唯一定位、实例级关联时，使用“编号”
- 被保人不再区分“成员号”和“被保人编号”，统一只保留 `insuredNo`
